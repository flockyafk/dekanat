## Готово
- Репозиторий (git, ветка main), каркас Next.js 15 + TypeScript strict + Tailwind 4.
- Схема SQLite (Prisma 6) по разделу 8 ТЗ, миграция `init`. Плюс таблица `LoginAttempt` для лимита попыток входа.
- Сид: 2 группы, 3 студента, 1 сотрудник, курсы, расписание, оценки, заявки, уведомления. Все данные вымышленные.
- Вход и выход: свои сессии в базе (в базе лежит хэш токена), cookie httpOnly + sameSite=lax + secure в production, bcrypt, zod, 5 попыток за 15 минут.
- Страницы: `/login`, `/` (заглушка «Сегодня» с кнопкой «Выйти»), `/about` (тестовые аккаунты). Подпись концепта в подвале каждой страницы.
- Тесты (7 штук, на отдельной базе `data/test.db`): вход, выход, лимит попыток, хэш, 404 для студента на `/staff`, студент А не видит профиль Б.
- `npm run lint`, `typecheck`, `test`, `build` проходят.
- Субагенты описаны в `.claude/agents/`.
