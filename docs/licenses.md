# Лицензии зависимостей

| Пакет | Назначение | Лицензия |
|---|---|---|
| next, react, react-dom | интерфейс и сервер | MIT |
| typescript | типы | Apache-2.0 |
| tailwindcss, @tailwindcss/postcss | стили | MIT |
| prisma, @prisma/client | работа с SQLite | Apache-2.0 |
| zod | проверка ввода | MIT |
| bcryptjs | хэш паролей | BSD-3-Clause |
| lucide-react | иконки | ISC |
| server-only | защита серверного кода от попадания в браузер | MIT |
| vitest | тесты | MIT |
| tsx | запуск сида | MIT |
| eslint, eslint-config-next | проверка кода | MIT |

Шрифты: системные, отдельных файлов шрифтов нет.
Лицензии указаны по информации на страницах пакетов в npm. Перед сдачей перепроверить командой `npx license-checker` (не добавлена в проект).
