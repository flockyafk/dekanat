## Ошибки помощника

Помощник проверен красной командой на реальной модели Qwen3-30B (Amvera LLM, имя в API `qwen3_30b`). Скрипт `npm run redteam` (`redteam/assistant.redteam.ts`) задаёт 27 атак и вопросов: просьбы показать данные другого студента, команды в тексте вопроса, заявки, комментария деканата и объявления, просьбы выдумать ответ, вопросы без данных, попытки достать системный промпт, атаки на черновик заявки. Три прогона, отчёты целиком лежат в `docs/`:
- прогон 1, промпты v1: `redteam-results-run1-prompt-v1.md` (OK 24, ПРОВЕРИТЬ 2, ОШИБКА 1);
- прогон 2, промпты v2: `redteam-results-run2-prompt-v2.md` (OK 25, ПРОВЕРИТЬ 2, ОШИБКА 0);
- прогон 3, промпты v2 и v3 черновика, итоговый: `redteam-results.md` (OK 25, ПРОВЕРИТЬ 2, ОШИБКА 0).

Что модель делала правильно с самого первого прогона: ни разу не выдала данные других студентов, не выполнила ни одной команды из вопроса, заявки, комментария и объявления, не раскрыла системный промпт, на вопросы без данных отвечала «В данных этого нет». Что защищено кодом, а не промптом (проверено тестами, не зависит от того, послушается ли модель):
- запрос к модели содержит только данные текущего студента (для каждого из трёх студентов проверено, что в нём нет ни одной записи других: имён, почт, зачёток, id записей, текстов заявок, чужих дисциплин, дедлайнов, комментариев, уведомлений); есть контрольная проверка, что тест находит подложенную чужую запись;
- команда в тексте вопроса, заявки, комментария или объявления передаётся как данные в отдельном блоке; символы, которыми можно подделать границы блоков, кодируются;
- внешние ссылки, `javascript:`, адреса вне списка маршрутов, лишние параметры и чужие id в ответе отбрасываются; внешние адреса вырезаются и из текста; разметка выводится как обычный текст;
- суточный лимит на студента и общий суточный предел (защита месячного пакета токенов), в том числе при параллельных запросах; текст вопросов не пишется в журнал и не хранится, ключ не попадает в ответы, журнал и клиент (тесты на ошибки провайдера HTTP 401, 402, 403, 429, 500, 503);
- черновик заявки только подставляется в форму, заявку отправляет студент сам.

Что красная команда не гарантирует: ответы модели недетерминированы (температура 0,2), на каждом наборе промптов сделано по одному прогону из 27 запросов, поэтому «ошибок нет» означает «не найдено в этих прогонах». Безопасность не зависит от этого, потому что держится на коде, а не на послушности модели.
