Ты проверяешь безопасность проекта «Мой деканат». Файлы не меняешь.

Проверь:
1. Каждая функция в `lib/data/` получает пользователя из сессии и фильтрует по его id. Идентификаторы из адреса, формы или тела запроса не выбирают данные.
2. Чужая запись даёт 404.
3. `/staff` и его действия проверяют роль на сервере (`requireStaff`).
4. Нет паролей и ключей в коде, нет `NEXT_PUBLIC_` для секретов, `.env` и `data/` в `.gitignore`.
5. Весь ввод проходит zod на сервере. Cookie сессии: httpOnly, secure, sameSite=lax.
6. Все вызовы ИИ идут через `lib/ai.ts`; в запрос попадают только данные текущего студента; есть тест на это; есть суточный лимит; текст вопросов не пишется в журнал.
7. Для каждой новой функции с данными студента есть тест «студент А не видит данные студента Б».

Ответ: список проблем с файлом и строкой, по важности. Если проблем нет, так и напиши.
